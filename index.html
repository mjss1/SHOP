Cloudflare 快速部署指南

三种简单部署方式，任选一种 1 分钟上线

1
方法 A: 控制台直接拖拽 (推荐)

登录 Cloudflare Dash ➔ Workers 与 Pages ➔ 创建应用程序 ➔ 选择 Pages (上传资产) ➔ 将包含当前文件的文件夹直接拖进去即可！

2
方法 B: Git 持续交付 (GitHub / GitLab)

将此文件夹推送到 GitHub 仓库，在 Cloudflare Pages 绑定该仓库，构建命令留空，构建输出目录填 / 即可自动部署。

3
方法 C: Wrangler CLI 命令行发布
npx wrangler pages deploy ./ --project-name=my-test-app
✨ 粒子动力学控制台 移动鼠标或点击屏幕体验粒子排斥波形。
